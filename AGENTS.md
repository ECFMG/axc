# Agent instructions

Read these files before adding or changing domain, application service, persistence, mongoose model, GraphQL, or REST code. Follow them. Do not invent a second layout.

## Read first

- `.agents/skills/cellix-architecture/SKILL.md` — the workflow. New features start from `@cellix/generator`. After that, change data and behavior only.
- `cellix-lint.config.json` — `writable` is where agent edits are allowed. `agentAccess` locks whole trees. Do not edit this file.
- `packages/cellix/generator/` — the generator package. Command flags are documented in the skill.
- `packages/cellix/lint/src/check.ts` — `@cellix/lint` entry. File roles, file body, visibility, and the dependency graph.
- `packages/cellix/lint/biome-shared.json` — the Biome rules. Root `biome.json` extends `@cellix/lint/biome` and adds only app-specific ignores.

## Do not edit

These are the control plane. A human changes them on purpose.

- `cellix-lint.config.json`
- `packages/cellix/lint/**`
- `packages/cellix/generator/**`
- `.cursor/hooks.json`
- `.cursor/hooks/**`

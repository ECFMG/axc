# agentCourses API

agentCourses is a dark software factory scaffold. HTTP capabilities are composed by `@apps/api` and served through Hono routes in `@axc/rest`.

- [Healthcheck](./healthcheck.md) — `GET /health`
- [Courses](./courses.md) — `GET /api/courses`
- [Enrollment requests](./enrollment-requests.md) — `POST /api/enrollment-requests`, `GET /api/enrollment-requests`, `GET /api/enrollment-requests/:id`, `PATCH /api/enrollment-requests/:id/status`

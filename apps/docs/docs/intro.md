# agentCourses API

agentCourses is a dark software factory scaffold. `@apps/api` composes the Hono routes in `@axc/rest`.

- [Healthcheck](./healthcheck.md) reports that the API process is running.
- [Course search](./api/courses.md) lists the sample catalog.
- [Enrollment requests](./api/enrollment-requests.md) create and review requests for active courses.

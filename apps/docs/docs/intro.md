# agentCourses API

agentCourses is a dark software factory scaffold. HTTP capabilities are composed by `@apps/api` and served through the Hono routes in `@axc/rest`.

- [Healthcheck](./healthcheck.md) — `GET /health`
- [Courses](./courses.md) — `GET /api/courses`, the course catalog search endpoint

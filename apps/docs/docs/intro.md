# agentCourses API

agentCourses is a dark software factory scaffold. `@apps/api` composes the Hono routes in `@axc/rest`.

* [Healthcheck](/healthcheck) reports that the API process is running.
* [Course catalog](/api/courses) searches the training courses.
* [Enrollment requests](/api/enrollment-requests) lets a learner request an active course and records each status change.

# agentCourses API

agentCourses is a dark software factory scaffold. `@apps/api` composes the Hono routes in `@axc/rest`.

## HTTP API

- [Healthcheck](./healthcheck.md) — `GET /health`
- [Course search](./api/courses.md) — `GET /api/courses`
- [Enrollment requests](./api/enrollment-requests.md) — create, review, and update enrollment requests

# agentCourses API

agentCourses is a dark software factory scaffold. `@apps/api` composes the HTTP API and `@axc/rest` serves it with Hono.

- [Healthcheck](./healthcheck.md) reports process health.
- [Course search](./api/courses.md) lists the training catalog.
- [Enrollment requests](./api/enrollment-requests.md) creates and reviews learner requests.

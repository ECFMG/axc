# agentCourses API

agentCourses is a dark software factory scaffold. `@apps/api` composes the HTTP API and `@axc/rest` serves it.

- [Healthcheck](./healthcheck.md) reports that the process is running.
- [Course catalog](./api/courses.md) searches the in-memory training catalog.
- [Enrollment requests](./api/enrollment-requests.md) lets a learner request an active course and lets a reviewer change that request's status.
